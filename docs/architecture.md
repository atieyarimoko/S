# Mars: 設計と実現可能性

調査日: 2026-11-03

## 実行環境

- ワークスペースは初期コミット直後で、既存アプリやテストはない。
- Ubuntu 24.04系コンテナ。Node.js 24、Python 3.14、SQLite 3.45を利用可能。
- コンテナに見える資源は2 vCPU、約7.8 GiB RAM、空きディスク約19 GiB。Ollamaとブラウザはインストールされていない。
- Python標準のHTTP/TLS・SQLiteが動作することを確認した。よって、まず外部パッケージなしのローカルWebアプリを作り、実行環境に不必要な依存を持ち込まない。

## 無料運用の判断

- **基盤:** Python標準ライブラリのHTTPサーバーとSQLiteを使う。アプリ自体に利用料、APIキー、外部DBは不要。ホストの稼働時間、保存容量、バックアップは利用者の実行環境に依存する。
- **推論:** ローカルOllamaをOpenAI互換形式で接続する。アプリはループバック接続だけを許可し、課金の有無を保証できない外部モデルは拒否する。モデルごとにライセンスが異なり、計算資源・電力・容量も必要。現コンテナではOllamaもGPUも確認できず、実用的な推論速度は保証できない。モデル未設定時はAIタスクを実行しない。
- **検索:** キー不要のDuckDuckGo HTMLとBing HTMLフォールバックを利用する。公開検索ページの利用可否・レート制限・規約・HTML形式は変わり得る。無料・無制限・安定とはみなさず、失敗時は出典を捏造せず失敗を報告する。検索語は検索事業者へ送られる。
- **ホスティング:** ローカル/自分で管理する常時稼働ホストが、無料枠の停止・実行時間制限を避ける最も単純な選択。ホストが停止している間、バックグラウンド処理は続かない。Cloudflare Workers Freeの公式制限は1日100,000リクエスト、HTTPリクエスト当たりCPU時間10 msであり、長いエージェント処理の実行基盤とはみなさない。Cloudflare Pagesは静的配信候補だが、永続タスク実行基盤ではない。
- **確認した一次資料:** [Ollama download](https://ollama.com/download)、[Ollama OpenAI compatibility](https://ollama.com/blog/openai-compatibility)、[Cloudflare Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/)、[Cloudflare Workers limits](https://developers.cloudflare.com/workers/platform/limits/)、[Cloudflare Pages limits](https://developers.cloudflare.com/pages/platform/limits/)。無料条件は変更されるため、導入時に再確認する。

## 全体設計

1. レスポンシブな日本語Web UIを同一オリジンで配信し、チャット、タスク、実行履歴、ファイル、記憶、設定をまとめる。
2. Python標準ライブラリのHTTP層とSQLiteを採用し、データはユーザーが管理するローカルディレクトリに置く。DBのトランザクションとチェックポイントを使い、会話ログとは別にタスク状態・計画・成果・次の作業を保存する。
3. タスクは永続キューで優先順位順に逐次実行する。起動時に処理中だった項目は、検索・ページ閲覧・ローカルメディア分析など読み取り専用の作業に限り、最後のチェックポイントから自動再開する。再試行と1回の実行量には上限を設ける。プロセス停止中の実行は主張しない。
4. エージェント実行器、モデル接続、検索、ページ取得、保存先を分離する。モデルなしでもタスクの記録・編集・再開は可能にする。OllamaなどOpenAI互換のローカル接続だけを使い、外部モデルAPIへの接続は許可しない。
5. Web調査は検索結果だけでなく公開ページ本文を取得し、URL・取得時刻・抽出本文を根拠として保存する。公開HTTP(S)以外、ループバック/プライベートIP、過大応答、危険なリダイレクトを拒否する。ページ本文は信頼できないデータとして扱い、命令として実行しない。コマンド実行ツールは設けない。
6. メール、投稿、課金、外部変更、完全削除、公開は初期実装の自動実行対象外とする。モデル入力を外部へ送信する接続も許可しない。
7. SQLiteのバックアップ/復元、ファイル操作のルート制限、任意の認証、ローカル接続の検証を実装する。認証の有無にかかわらずインターネットへ公開しない。
8. 添付ファイルはローカル管理領域に保存する。文書テキストは最大3件・各20,000文字まで。画像・動画はPillowで検証した画像、またはffprobe/ffmpegで抽出した時刻付きフレームをOpenAI互換の画像入力としてローカルモデルへ渡す。
9. 画像解析はOpenAI互換APIの `image_url` 形式を使う。実際に画像対応のモデルを選ぶ必要があり、テキスト専用モデルでの解析は成功扱いにしない。動画は最大8フレームを時刻情報付きでサンプリングし、特定時間の質問は該当区間を優先する。タスク添付と分析結果は既存のSQLite findings/チェックポイントに記録する。

## 現在の実装範囲と制約

- Phase 1〜7のローカル基本機能（タスク、検索、記憶、チャット、限定ファイル管理、完全バックアップ/復元、画像・動画入力、検算付き計算とCSV/JSON分析）を実装。常時稼働はホストの運用に依存する。
- DB、バックアップ、保存ファイルには所有者限定のアクセス権を設定する。完全バックアップは合計250 MBまで。
- `MARS_PASSWORD` 設定時はログイン保護を有効化できる。既定サーバーはループバックのみ。HTTPサーバーのため公開ネットワークからの安全なリモートアクセスには未対応。
- Hostヘッダーはループバックのホスト名/IPに限定する。これはHTTPSやリモートアクセス用のセキュリティ境界の代替ではない。
- モデル接続先はOpenAI互換形式のループバックに限定し、外部モデルホストは拒否する。画像分析には画像入力対応モデルが必要。Ollama・モデルはこの環境に未設定で、モデル固有のライセンス・必要RAM・互換性・速度は未確認。選択したモデルのライセンスを取得前に個別確認する必要がある。
- 画像は12 MB・4,000万画素、動画は25 MB・30分、添付は合計3件・動画1件・動画あたり最大8フレーム。動画処理にはOSの `ffmpeg` / `ffprobe` が必要。FFmpegは別途導入する。音声文字起こしは未対応。
- ローカル推論はAPI従量料金なしだが、ホストの電力・計算資源・モデルライセンスは別。アプリから有料モデルAPIへの切替は行わない。
- DuckDuckGo HTMLが利用できない場合はBing HTMLを使う。いずれも利用条件・レート制限・HTML形式・稼働は保証されない。実環境でライブ検索と公開ページ取得を確認済み。
- DNS解決した公開IPへ直接TLS接続し、HTTPクライアントによる再解決の隙を防止。各リダイレクト先も再検証する。アプリHTTPサーバーはHostをループバック名/IPに限定し、公開ネットワーク越しのアクセスには使わない。
- 自動操作はWeb検索、公開ページ閲覧、管理領域内の読み取り・ファイル操作、制限付き計算・CSV/JSON分析のみ。任意Python/シェルコード実行、メール、投稿、課金、外部変更、削除は実装しない。
- 計算は式512文字・AST 128要素・統計リスト1,000件まで。データ分析はUTF-8 CSV/JSON、入力1 MB・20,000行・100列・20数値列まで。外部Python依存を追加せず、標準ライブラリで実行する。
- PDF/DOCX/XLSXはテキスト抽出のみ。依存ライブラリは `requirements.txt` に記載し、抽出サイズ・ファイルサイズを制限する。
- スキャンPDFのOCR、PDF/Officeのレイアウト再現・編集書き戻し、音声文字起こし、設定値のWeb編集、会話履歴の削除は未実装。実アプリのブラウザー・タブレット実機表示と実モデル精度は未検証。

各段階で未実装・未検証を明示し、利用料や不可逆な外部操作をユーザーの確認なしに導入しない。
