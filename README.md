# Mars

個人用のローカル優先AI調査・タスク管理アシスタントです。設計と現在の開発状況は [docs/architecture.md](docs/architecture.md) と [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md) を参照してください。

## 起動

Python 3.11以降で動作します。画像検証・縮小にはPillow、PDF/DOCX/XLSXの読み取りには追加ライブラリを使います。動画分析にはOS側の `ffmpeg` と `ffprobe` が必要です（Pythonパッケージには含まれません）。

```bash
python3 -m pip install -r requirements.txt
python3 mars.py
```

ブラウザーで `http://127.0.0.1:8000` を開きます。`MARS_PORT` と `MARS_DATA_DIR` でポート・保存先を変更できます。サーバーはループバック接続のみで待ち受けます。ログイン保護を有効にする場合は12文字以上のパスワードを環境変数で設定します。

```bash
MARS_PASSWORD="十分に長い個人用パスワード" python3 mars.py
```

ログインセッションは12時間で期限切れになります。パスワード未設定時は認証なしですが、サーバーはこの端末内だけで待ち受けます。インターネットや共有ネットワークへ公開する設定は提供していません。

## AI実行

Ollamaを別途インストールし、利用するモデルを取得してから、そのモデル名を指定してMarsを起動します。

```bash
MARS_MODEL="ollama list に表示されるモデル名" python3 mars.py
```

初期接続先は `http://127.0.0.1:11434/v1/chat/completions` です。モデル未設定時はタスクを保存するだけで、自動実行しません。Ollama本体はこのリポジトリには含まれず、モデルごとのライセンス・必要RAM・速度も異なります。モデル取得前に [Ollama Library](https://ollama.com/library) で確認してください。

AIモデルはローカル接続だけを許可します。外部モデルAPIや `MARS_ALLOW_REMOTE_MODEL` による例外は利用できず、課金APIへフォールバックしません。モデルのウェイトはMarsに同梱していないため、選択したモデルのライセンスと利用条件を確認してから取得してください。

ライセンス候補として確認したIBMの[Granite 3.3 2B Instruct](https://huggingface.co/ibm-granite/granite-3.3-2b-instruct)はモデルカードでApache-2.0とされ、日本語を含む複数言語を記載しています。[Granite Vision 3.2 2B](https://huggingface.co/ibm-granite/granite-vision-3.2-2b)もモデルカードでApache-2.0ですが、画像指示は英語対応と記載されています。いずれもこの環境では未導入・未検証で、Ollama向け配布物の互換性・正確な量子化版の条件は別途確認が必要です。対照的に[Qwen2.5 3Bのライセンス](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct/blob/main/LICENSE)は非商用目的に限定するため、一般用途の無条件な無料モデルとしては推奨しません。

画像・動画分析には、OpenAI互換の `image_url` 入力を受け付ける**画像対応モデル**が必要です。テキスト専用モデルでは分析できません。ローカル利用では、画像対応モデルをOllama等に用意し、そのモデル名を `MARS_MODEL` に設定します。動画はローカルのFFmpegで最大8フレームを時刻付きで抽出し、そのフレームをモデルに渡します。1画像12 MB・4,000万画素、1動画25 MB・30分を上限とします。形式・モデルが非対応の場合はエラーを表示します。

チャット履歴・タスクの分析結果はローカルSQLiteへ保存されます。タスク実行では、LLMに計算値を推測させず、制限付きの数式評価器で四則演算・べき乗・平方根・対数・平均・中央値・標準偏差などを計算し、異なる精度で再計算します。管理領域内のCSV/JSONは最大1 MB・20,000行として集計・分類・線形傾向分析でき、元ファイルを再読込して全結果を再検証します。CSV/JSONの数値分析や計算結果はタスクの検証可能な根拠として保存され、完了直前に元データの変更も検査します。任意コードやシェルは実行しません。

チャットから画像・動画をアップロードしてプレビューでき、複数画像の比較、動画全体の時間軸サンプリング、指定時間のフレーム抽出、追加質問が可能です。文書・画像・動画は合わせて3件まで添付でき、動画は1件までです。分析結果はタスクの目的に転記したり、記憶に保存したりできます。タスクには保存済みメディアを指定でき、各分析結果がチェックポイントとして保存されるため、中断後も再利用されます。メディア分析に失敗したタスクは原因を記録し、タスクを再開すると再試行します。

モデルへの入力はループバック上のローカルモデルに限られ、外部モデルへの送信機能は無効です。ローカル利用はAPI利用料不要ですが、ハードウェア・電力が必要です。Web検索はDuckDuckGo/Bingの公開検索ページへ検索語を送ります。検索は有料APIや課金フォールバックを使いませんが、外部サイトの利用条件・継続提供は保証されず、利用不能時は失敗を報告します。音声文字起こしは未実装です。

検索はDuckDuckGo HTMLを使い、利用できない場合はBing HTMLへフォールバックします。いずれもキー不要ですが、無料・無制限・安定稼働は保証されず、検索語は検索事業者へ送られます。ページ閲覧はDNS解決先を確認・固定した公開HTTPS本文に限ります。

## ファイル・バックアップ

ファイル画面では `data/files/` 内にフォルダーを作成し、TXT・MD・CSV・JSON・LOGを読み書き・検索・ダウンロードできます。端末から複数ファイルを取り込めます（既存ファイルは上書きしません）。自律タスクもこの保存領域だけでテキストを読み、新規ファイルを作成できます。既存ファイルの編集にはタスク内で事前に読み込んだ内容のSHA-256が必要です。タスクが作成・編集したテキスト、Markdown、CSV、JSONは再読込し、CSV/JSON構文、SHA-256、タスク完了直前のファイル状態を検証します。成果物はタスク記録からプレビュー・ダウンロードできます。PDF・DOCX・XLSXからテキストを抽出し、PNG・JPG・JPEG・WEBP画像とMP4・MOV・WEBM動画を保存・プレビュー・チャット添付できます。テキストは1 MB、文書は20 MB、画像は12 MB、動画は25 MBまでです。文書の編集・再保存、PDFのスキャン画像OCR、音声文字起こし、レイアウト・書式の完全保持は未対応です。完全削除は画面で確認します。

「完全バックアップをダウンロード」で会話・タスク・記憶と `data/files/` のファイルをZIP形式で保存できます。最大サイズは250 MBです。復元は未完了タスクがないときに限り、DBとファイル領域を置き換えます。復元前の完全バックアップは `data/backups/` へ退避します。以前のSQLite単体バックアップも引き続き復元でき、その場合ファイル領域は変更されません。

## 開発状況

タスク管理、自律計画・限定ツール実行、検算付き計算、CSV/JSON分析、検索、公開ページ閲覧、出典保存、チャット、5分類の編集可能な記憶、制限付きテキスト・文書・画像・動画管理、画像対応モデルへのマルチモーダル入力、動画フレームの時間軸分析、タスクチェックポイント、任意のログイン保護、DB・ファイル領域を含む完全バックアップ/復元を実装しています。モックモデルによる画像・タスク連携テストは成功していますが、実AIモデルでの精度・互換性検証、実動画ファイルを使った抽出確認はこの環境では未実施です。HTTPS経由のリモートアクセス、音声文字起こし、文書OCRと書式保持は未対応です。詳細は [docs/architecture.md](docs/architecture.md) と [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md) を参照してください。
