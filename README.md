# Mars

個人用のローカル優先AI調査・タスク管理アシスタントです。設計と現在の開発状況は [docs/architecture.md](docs/architecture.md) と [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md) を参照してください。

## 起動

Python 3.11以降で動作します。PDF・XLSXの読み取りには追加ライブラリを使います。

```bash
python3 -m pip install -r requirements.txt
python3 mars.py
```

ブラウザーで `http://127.0.0.1:8000` を開きます。`MARS_PORT` と `MARS_DATA_DIR` でポート・保存先を変更できます。サーバーはループバック接続のみで待ち受けます。ログイン保護を有効にする場合は12文字以上のパスワードを環境変数で設定します。

```bash
MARS_PASSWORD="十分に長い個人用パスワード" python3 mars.py
```

ログインセッションは12時間で期限切れになります。パスワード未設定時は認証なしですが、サーバーはこの端末内だけで待ち受けます。インターネットや共有ネットワークへ公開する設定は提供していません。

## AI実行

Ollamaを別途インストールし、利用するモデルを取得してから、そのモデル名を指定してMarsを起動します。

```bash
MARS_MODEL="ollama list に表示されるモデル名" python3 mars.py
```

初期接続先は `http://127.0.0.1:11434/v1/chat/completions` です。モデル未設定時はタスクを保存するだけで、自動実行しません。Ollama本体はこのリポジトリには含まれず、モデルごとのライセンス・必要RAM・速度も異なります。モデル取得前に [Ollama Library](https://ollama.com/library) で確認してください。

OpenAI互換の外部モデルも任意設定できますが、依頼内容や調査資料がその事業者へ送られます。料金が発生する場合もあるため、利用条件を確認し、`MARS_MODEL_URL`、`MARS_MODEL`、必要なら `MARS_MODEL_API_KEY` を環境変数で設定した上で、送信を明示する `MARS_ALLOW_REMOTE_MODEL=1` を指定してください。APIキーをソースやSQLiteには保存しません。

チャット履歴はローカルSQLiteへ保存され、関連する記憶がモデルの回答に使われます。ファイル画面からTXT/MD/CSV/JSON/LOGを最大3件添付でき、各ファイルの先頭20,000文字が回答に使われます。外部モデルを選んでいる場合は会話文・添付ファイル・関連記憶が外部送信されるため、機密情報を入力・添付しないでください。

検索はDuckDuckGo HTMLを使い、利用できない場合はBing HTMLへフォールバックします。いずれもキー不要ですが、無料・無制限・安定稼働は保証されず、検索語は検索事業者へ送られます。ページ閲覧はDNS解決先を確認・固定した公開HTTPS本文に限ります。

## ファイル・バックアップ

ファイル画面では `data/files/` 内にフォルダーを作成し、TXT・MD・CSV・JSON・LOGを読み書き・検索・ダウンロードできます。端末から複数ファイルを取り込めます（既存ファイルは上書きしません）。PDF・DOCX・XLSXからテキストを抽出して表示・チャット添付できます。テキストファイルは1 MB、文書は20 MBまでです。文書の編集・再保存、PDFのスキャン画像OCR、レイアウト・書式の完全保持は未対応です。完全削除は画面で確認します。画像・動画の内容解析も未対応です。

「完全バックアップをダウンロード」で会話・タスク・記憶と `data/files/` のファイルをZIP形式で保存できます。最大サイズは250 MBです。復元は未完了タスクがないときに限り、DBとファイル領域を置き換えます。復元前の完全バックアップは `data/backups/` へ退避します。以前のSQLite単体バックアップも引き続き復元でき、その場合ファイル領域は変更されません。


## 開発状況

タスク管理、自律計画・限定ツール実行、検索、公開ページ閲覧、出典保存、チャット、5分類の編集可能な記憶、制限付きテキスト・PDF・DOCX・XLSX管理、任意のログイン保護、DB・ファイル領域を含む完全バックアップ/復元を実装しています。ライブ検索とNASAページ取得は検証済みですが、実AIモデルは未検証です。HTTPS経由のリモートアクセス、画像・動画解析、文書OCRと書式保持は未対応です。詳細は [docs/architecture.md](docs/architecture.md) と [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md) を参照してください。
