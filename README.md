# Mars

個人用のローカル優先AI調査・タスク管理アシスタントです。設計と現在の開発状況は [docs/architecture.md](docs/architecture.md) と [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md) を参照してください。

## 起動

Python 3.11以降で動作します。画像検証・縮小にはPillow、PDF/DOCX/XLSXの読み取りには追加ライブラリを使います。動画分析にはOS側の `ffmpeg` と `ffprobe` が必要です（Pythonパッケージには含まれません）。

```bash
python3 -m pip install -r requirements.txt
python3 mars.py
```

ブラウザーで `http://127.0.0.1:8000` を開きます。`MARS_PORT` と `MARS_DATA_DIR` でポート・保存先を変更できます。サーバーはループバック接続のみで待ち受けます。ログイン保護を有効にする場合は12文字以上のパスワードを環境変数で設定します。

```bash
MARS_PASSWORD="十分に長い個人用パスワード" python3 mars.py
```

ログインセッションは12時間で期限切れになります。パスワード未設定時は認証なしですが、サーバーはこの端末内だけで待ち受けます。インターネットや共有ネットワークへ公開する設定は提供していません。

## AI実行

Ollamaを別途インストールし、利用するモデルを取得してから、そのモデル名を指定してMarsを起動します。

```bash
MARS_MODEL="ollama list に表示されるモデル名" python3 mars.py
```

初期接続先は `http://127.0.0.1:11434/v1/chat/completions` です。モデル未設定時はタスクを保存するだけで、自動実行しません。Ollama本体はこのリポジトリには含まれず、モデルごとのライセンス・必要RAM・速度も異なります。モデル取得前に [Ollama Library](https://ollama.com/library) で確認してください。

画像・動画分析には、OpenAI互換の `image_url` 入力を受け付ける**画像対応モデル**が必要です。テキスト専用モデルでは分析できません。ローカル利用では、画像対応モデルをOllama等に用意し、そのモデル名を `MARS_MODEL` に設定します。動画はローカルのFFmpegで最大8フレームを時刻付きで抽出し、そのフレームをモデルに渡します。1画像12 MB・4,000万画素、1動画25 MB・30分を上限とします。形式・モデルが非対応の場合はエラーを表示します。

OpenAI互換の外部モデルも任意設定できますが、依頼内容や調査資料がその事業者へ送られます。料金が発生する場合もあるため、利用条件を確認し、`MARS_MODEL_URL`、`MARS_MODEL`、必要なら `MARS_MODEL_API_KEY` を環境変数で設定した上で、送信を明示する `MARS_ALLOW_REMOTE_MODEL=1` を指定してください。APIキーをソースやSQLiteには保存しません。

チャット履歴・タスクの分析結果はローカルSQLiteへ保存されます。チャットから画像・動画をアップロードしてプレビューでき、複数画像の比較、動画全体の時間軸サンプリング、指定時間のフレーム抽出、追加質問が可能です。文書・画像・動画は合わせて3件まで添付でき、動画は1件までです。分析結果はタスクの目的に転記したり、記憶に保存したりできます。タスクには保存済みメディアを指定でき、各分析結果がチェックポイントとして保存されるため、中断後も再利用されます。メディア分析に失敗したタスクは原因を記録し、タスクを再開すると再試行します。

外部モデルを選んだ場合、会話・添付文書・画像・動画から抽出したフレーム・関連記憶は、依頼時に設定した外部事業者へ送信されます。Marsは添付内容を明示なしに別サービスへ送信しません。ローカルモデルを使う場合、モデルへの入力は端末内にとどまります。外部APIの無料枠・料金は提供者・モデル・入力画像数で異なるため、事前に提供者へ確認してください。ローカル利用はAPI利用料不要ですが、ハードウェア・電力が必要です。音声文字起こしは未実装です。

検索はDuckDuckGo HTMLを使い、利用できない場合はBing HTMLへフォールバックします。いずれもキー不要ですが、無料・無制限・安定稼働は保証されず、検索語は検索事業者へ送られます。ページ閲覧はDNS解決先を確認・固定した公開HTTPS本文に限ります。

## ファイル・バックアップ

ファイル画面では `data/files/` 内にフォルダーを作成し、TXT・MD・CSV・JSON・LOGを読み書き・検索・ダウンロードできます。端末から複数ファイルを取り込めます（既存ファイルは上書きしません）。PDF・DOCX・XLSXからテキストを抽出し、PNG・JPG・JPEG・WEBP画像とMP4・MOV・WEBM動画を保存・プレビュー・チャット添付できます。テキストは1 MB、文書は20 MB、画像は12 MB、動画は25 MBまでです。文書の編集・再保存、PDFのスキャン画像OCR、音声文字起こし、レイアウト・書式の完全保持は未対応です。完全削除は画面で確認します。

「完全バックアップをダウンロード」で会話・タスク・記憶と `data/files/` のファイルをZIP形式で保存できます。最大サイズは250 MBです。復元は未完了タスクがないときに限り、DBとファイル領域を置き換えます。復元前の完全バックアップは `data/backups/` へ退避します。以前のSQLite単体バックアップも引き続き復元でき、その場合ファイル領域は変更されません。

## 開発状況

タスク管理、自律計画・限定ツール実行、検索、公開ページ閲覧、出典保存、チャット、5分類の編集可能な記憶、制限付きテキスト・文書・画像・動画管理、画像対応モデルへのマルチモーダル入力、動画フレームの時間軸分析、タスクチェックポイント、任意のログイン保護、DB・ファイル領域を含む完全バックアップ/復元を実装しています。モックモデルによる画像・タスク連携テストは成功していますが、実AIモデルでの精度・互換性検証、実動画ファイルを使った抽出確認はこの環境では未実施です。HTTPS経由のリモートアクセス、音声文字起こし、文書OCRと書式保持は未対応です。詳細は [docs/architecture.md](docs/architecture.md) と [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md) を参照してください。
